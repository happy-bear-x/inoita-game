# 界面资源与调试面板优化

本计划覆盖界面改造时需要完成的资源管理与调试入口。素材使用权、会话退出、剧情索引与战斗加载的现有机制见 [架构说明](architecture.md)，本机调试标记接口见 [调试说明](debugging.md)。

## 界面素材

首屏保留操作栏和共用图标图集，菜单按实际使用加载图片。对白保留当前和下一段已准备的立绘。按状态栏和小地图迁移后的实际使用情况，清理控制皮肤、状态栏和小地图的重复图片，并分别验证网页界面和游戏画布首屏。

商店装备首次打开时读取，品级数据复用已有角色数值表。

## 会话引用

回标题时解除面板订阅，以及界面、调试面板和现场目录对旧会话的引用。退出回调只清理对应旧局；读档失败或取消后原局继续可用。

## 调试标记界面

面板接入本机数据库的异步标记接口，保留「记标记」「回到最近」，增加历史标记的分页选择、恢复和删除。列表只读摘要，恢复时才读取正文。写入完成才提示成功；覆盖失败或空间不足时保留原标记。

## 设备验收

使用同一设备、同一存档核对首次施法、换人后的飞弹与持续效果、黑暗空间演出，以及退标题与新开一局后的内存。自动测试和按图片尺寸计算的资源量不能代替实际画面与设备内存测量。
