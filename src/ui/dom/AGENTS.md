# src/ui/dom

屏幕界面的 DOM 组件、图片、输入和生命周期。外观沿用原版素材，布局与游戏状态取自上层接口。

- 图片使用资源版本号；同一图集共享加载，组件关闭释放持有的资源。
- 组件按稳定标识复用节点，只更新变化的内容、位置和可见性。
- 图片与文字在同一组件内排层；确认框和全屏遮挡同时管理显示和输入。
- 指针捕获在松手、取消、失去捕获、隐藏和销毁时清理；每次物理输入只执行一次动作。
- 键盘动作通过统一 InputRouter 路由，游戏规则由已有动作接口执行。
- 自动化测试使用 Node 和 DOM 替身；实际画面由用户验收。

## 文件

- `dom-ui.ts`、`menu-text.ts`：DOM 层、文字和菜单排版。
- `assets.ts`：图片、图集切片、预加载与资源持有计数。
- `components.ts`：组件容器、图片、按钮与指针生命周期。

- `action-controls.ts`：轮盘图片、数量、SVG 冷却与多指动作输入。
- `status-hud.ts`：主控者、队友和目标的头像、数值槽、状态图标与点击；随场景显隐，数据没变时复用节点与图片。
- `minimap.ts`：合并 SVG 地形与 DOM 标记，图标使用原素材尺寸，标记按身份复用并随地图释放。
- `cooldown.ts`：轮盘与电脑技能行共用的 SVG 冷却扇形、前沿、圆环和秒数。
- `computer-skill-hud.ts`：只读六格技能行，图标、冷却和物品数量共用容器，整行拦截地图点击。
